# iLovePDF Clone

A frontend UI clone of the iLovePDF website built using pure HTML and CSS.
This project was created to practice real-world layout building and improve core frontend skills.

## 📚 About the Project

The goal of this project was to recreate the visual layout of iLovePDF to strengthen HTML structure and CSS styling skills without using frameworks or JavaScript.

## 🛠️ Built With

* HTML5
* CSS3

## 🎯 Key Learnings

* Layout structuring
* Spacing & alignment
* CSS positioning
* UI replication from real websites
* Clean file organization

## 🚧 Limitations

* Not responsive yet
* Static UI only
* Tools are not functional

## 🔮 Future Improvements

* Make fully responsive
* Add JavaScript functionality
* Add PDF tool interactions
* Improve accessibility

## ▶️ Run Locally

Open `index.html` in your browser.
